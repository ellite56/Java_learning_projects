# Shop API with gRPC Authentication

Командный учебный проект Школы 21: API магазина и отдельный сервис авторизации, взаимодействующие по gRPC.

## Состав

- shop-service — REST API клиентов, поставщиков, товаров и изображений.
- auth-service — регистрация, вход, выпуск и проверка JWT, смена пароля.
- database — схемы PostgreSQL без строк данных.
- Контракт gRPC находится в src/main/proto/auth.proto каждого сервиса.

## Стек

Java, Spring Boot, Spring Data JPA, PostgreSQL, gRPC, Protocol Buffers, JWT, Spring Security Crypto, Gradle.

Сервис авторизации использует PasswordEncoder. Магазин обращается к нему через gRPC-клиент и проверяет доступ к REST API через interceptor.

## Настройка

Подготовьте отдельную базу PostgreSQL для каждого сервиса и импортируйте соответствующий файл из database.

Переменные окружения для каждого сервиса:
- DB_URL — адрес базы;
- DB_USER — пользователь (по умолчанию postgres);
- DB_PASSWORD — пароль.
Для auth-service задайте также секрет JWT через переменную, указанную в его application.properties.

Настройки адресов и портов gRPC находятся в application.properties.
Каждый сервис запускается из своего каталога: sh ./gradlew bootRun (Windows: .\gradlew.bat bootRun).
Требования к JDK и зависимости сохранены в build.gradle.
