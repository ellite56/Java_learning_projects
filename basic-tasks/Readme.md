# Smart Utilities

Учебный проект на Java.

Проект состоит из нескольких небольших программ для практики базовых возможностей языка Java.

## Что есть в проекте

- расчет периметра треугольника;
- перевод секунд в формат `hh:mm:ss`;
- поиск числа Фибоначчи;
- среднее арифметическое отрицательных чисел;
- поиск чисел с одинаковой первой и последней цифрой;
- сортировка массива выбором;
- поиск минимального и максимального значения;
- проверка возрастающей последовательности;
- фильтрация строк;
- поиск совершеннолетних пользователей.

## Технологии

- Java
- Gradle
- Arrays
- Lists
- Files
- Stream API
