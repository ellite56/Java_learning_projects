# Pet Info

Учебный проект на Java.

Проект состоит из нескольких небольших заданий про работу с питомцами.  
В нем я тренировался работать с ООП, классами, наследованием, интерфейсами, коллекциями, Stream API и потоками.

## Что есть в проекте

- создание списка питомцев;
- классы `Dog`, `Cat`, `Hamster`, `GuineaPig`;
- абстрактный класс `Animal`;
- расчет количества корма для питомцев;
- разделение животных на травоядных и всеядных;
- работа со Stream API;
- асинхронное выполнение прогулок питомцев;
- собственный итератор для списка животных.
