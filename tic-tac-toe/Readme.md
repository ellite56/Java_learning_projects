# Tic-Tac-Toe

Учебный проект на Java(School 21).

Это веб-приложение для игры в крестики-нолики.  
Проект сделан с использованием Spring.

## Что есть в проекте

- игровое поле;
- текущая игра с UUID;
- проверка правильности хода;
- проверка окончания игры;
- ход компьютера;
- хранение нескольких игр одновременно.

## Технологии

- Java
- Spring
- Gradle
- REST API

## Цель проекта

Проект был сделан для практики Java, Spring и простой архитектуры веб-приложения.
